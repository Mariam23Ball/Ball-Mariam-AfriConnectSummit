## Description du projet

AfriConnect Summit 2026 est un site web responsive présentant une conférence internationale dédiée aux nouvelles technologies, à l'innovation et à l'entrepreneuriat en Afrique.

Le site permet de découvrir le programme des conférences, les intervenants, les informations de contact ainsi que le formulaire d'inscription.

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Git & GitHub
- Bootstrap Icons
- Google Fonts

---

## Fonctionnalités JavaScript

- Dark Mode avec mémorisation grâce à LocalStorage
- Menu responsive (Hamburger)
- Compte à rebours jusqu'au sommet
- Compteurs animés
- Onglets interactifs de la page Programme
- Filtre des intervenants
- Bouton Retour en haut
- Mise à jour automatique de l'année dans le footer
