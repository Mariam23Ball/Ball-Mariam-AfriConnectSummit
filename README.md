# AfriConnect Summit 2026

## Présentation

AfriConnect Summit 2026 est un site web vitrine développé dans le cadre d'un projet de Technologie Web.

L'objectif est de présenter une conférence internationale fictive consacrée à l'innovation, au numérique et à l'entrepreneuriat en Afrique.

---

## Fonctionnalités

- Navigation responsive
- Mode sombre / Mode clair
- Menu hamburger pour mobile
- Compteur avant le début de l'événement
- Compteurs animés des statistiques
- Programme avec onglets interactifs
- Filtrage des intervenants par catégorie
- Formulaire d'inscription
- Carte Google Maps intégrée
- FAQ interactive
- Bouton de retour en haut de page
- Animations au défilement

---

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Google Fonts
- Git et GitHub
